Architecture

⚙
Direct OS syscalls
getdents64 on Linux, FindFirstFileW on Windows, readdir on macOS. No libc wrappers, no Python os module overhead.
⟳
Multi-threaded worker pool
N threads auto-detected from CPU core count. All threads running before the first directory is opened.
▣
Slab path allocator
Each thread allocates one contiguous block before scanning begins. Zero heap allocation during traversal regardless of filesystem size.
≡
Per-thread statistics
No shared counters during file counting. Each thread writes only to its own ScanStats struct. Results merged after all threads join.
◈
Bounded memory at any scale
Memory usage capped by the queue and path slabs. Scanning 50M files uses no more memory than scanning 50K.
↺
GIL released for full scan
Worker threads operate under Py_BEGIN_ALLOW_THREADS for their entire lifetime. Re-acquired only for progress callback and final dict construction.
